# Controle Financeiro

Sistema desktop para **cadastro, edição, exclusão e consulta** de receitas e despesas, com geração de relatórios por categoria.

## Tecnologias

- **Python 3.10+**
- **Flet** (interface desktop)
- **SQLite** (banco local)

## Funcionalidades

- Cadastrar receitas e despesas
- Editar e excluir lançamentos
- Consultar saldo atual em tempo real
- Relatório por categoria com receitas, despesas e resultado
